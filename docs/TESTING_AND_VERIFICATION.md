## What Each Test Proves

### Matrix Dimension Verification

Confirms that the image is resized to:

```text
A = 64 x 64
```

### Normalized Value Range Verification

Confirms:

```text
0 <= A[i, j] <= 1
```

The UI displays matrix min/max and a normalized range check.

### Rank Verification

Confirms `rank(A)` is calculated from matrix `A` using NumPy, not from selected `k`.

### C = A^T A Verification

The implementation constructs `C` from the uploaded image matrix using:

```text
matrix.T @ matrix
```

### Symmetry Verification

The current UI does not explicitly display a separate symmetry boolean, but `C = A^T A` is mathematically symmetric and the code uses a symmetric eigensolver. A previous direct check confirmed symmetry for the tested image. The current code displays `C` dimensions and eigenvalue checks.

### Eigenvalue Sorting Verification

`math_pipeline.py` checks:

```text
np.all(np.diff(eigenvalues) <= 1e-10)
```

and passes the result to the UI as `eigenvalues_sorted`.

### Eigenvalue Nonnegative Tolerance Check

`math_pipeline.py` checks:

```text
np.min(eigenvalues) >= -1e-10
```

and passes the result to the UI as `eigenvalues_nonnegative`.

### Projection Dimension Verification

The UI displays:

```text
(64 x 64)(64 x k) = 64 x k
```

using values generated by the pipeline.

### Reconstruction Dimension Verification

The UI displays:

```text
(64 x k)(k x 64) = 64 x 64
```

using values generated by the pipeline.

### Orthogonality Verification

The code calculates:

```text
||V_k^T V_k - I_k||_F
```

and marks verified if the error is less than `1e-8`.

### Reconstruction Error Verification

The code calculates:

```text
||A - A_k||_F
```

and:

```text
||A - A_k||_F / ||A||_F x 100
```

### Component Comparison Verification

For each `k` in:

```text
1, 5, 10, 20, 32, 64
```

the code independently computes:

```text
P = A V_k
A_k = P V_k^T
error = ||A - A_k||_F
```

## Known Limitations and Edge Cases

- The project resizes every image to `64 x 64`, so very detailed images lose visual detail before analysis.
- The current app does not store analysis results in a database.
- Uploaded images are saved to `media/uploads`; there is no cleanup workflow in the application.
- `k` is clamped between `1` and the number of matrix columns.
- The form allows image upload to be optional so a previously uploaded image can be reused through the hidden `image_name` field.
- Matplotlib is not used; eigenvalue visualization is drawn with JavaScript canvas.

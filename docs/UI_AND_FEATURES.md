# UI and Features

This file documents the interface features that currently exist.

## Page Title

The browser page title is:

```text
Image Transformation and Eigen-Feature Analyzer
```

The visible header identifies the project as a Linear Algebra & Vector Calculus mini-project.

## Visual Design Philosophy

The UI uses a clean university engineering/scientific style:

- Light background
- Dark readable typography
- Subtle borders
- Simple cards
- Mathematical notation
- Responsive layout

It does not use AI branding, glowing effects, glassmorphism, or dashboard-style fake statistics.

## Upload Interface

The page contains an upload form with:

- Image file input
- Dominant component selector `k`
- Run Analysis button

The form submits to the Django view and triggers the mathematical pipeline.

## k / Component Selector

The UI uses an HTML range input:

```text
min = 1
max = result.max_k or 64
default = 10
```

The datalist marks:

```text
1, 5, 10, 20, 32, 64
```

JavaScript updates the visible selected k value.

## Workflow Navigation

The workflow displayed near the top is:

```text
01 Image -> Matrix
02 Matrix Rank
03 Eigen Analysis
04 Component Selection
05 Projection
06 Reconstruction
07 Error Analysis
08 Interpretation
```

## Result Cards

After analysis, summary cards show:

- Matrix size
- Rank
- Selected k
- Min pixel
- Max pixel
- Frobenius error
- Relative error
- Orthogonality status

All values come from the mathematical result dictionary returned by `math_pipeline.py`.

## Original and Reconstructed Images

The UI displays:

- Original `64 x 64` grayscale matrix as an image
- Reconstructed image for selected `k`

The display images are generated from matrix values by `matrix_to_data_uri`.

## Mathematical Formula Sections

The page shows formula sections for:

- `A in R^(64 x 64)`
- `rank(A)`
- `C = A^T A`
- `C v = lambda v`
- `V_k = [v_1 v_2 ... v_k]`
- `P = A V_k`
- `A_k = P V_k^T`
- Absolute and relative error formulas

## Matrix Preview

The UI displays the first 10 rows and columns of normalized matrix `A`.

This is generated by:

```text
visualization.py -> matrix_preview(matrix, rows=10, cols=10)
```

## Eigenvalue Spectrum

The eigenvalue spectrum is displayed on an HTML canvas.

The values are passed through:

```text
result.eigenvalues
```

and drawn by:

```text
analyzer/static/analyzer/app.js
```

## Eigenvector Preview

The UI includes a dedicated eigenvector preview section.

It displays:

- `C = A^T A`
- `C v = lambda v`
- `V_5 = 64 x 5`
- First 10 entries of `v_1` through `v_5`

The displayed values come from:

```text
result.dominant_eigenvectors_preview
```

which is produced from the calculated eigenvector matrix.

## Projection Preview

The UI displays a preview of:

```text
P = A V_k
```

It also shows dimensions:

```text
A = 64 x 64
V_k = 64 x k
P = 64 x k
```

## Orthogonality Verification

The UI displays:

```text
V_k^T V_k ~= I_k
```

and shows:

- Orthogonality error
- Verified / Not Verified status
- Eigenvector preview table

## Component Comparison

The component comparison table displays:

| k | Frobenius Error | Relative Error (%) |
|---|---|---|
| 1 | calculated | calculated |
| 5 | calculated | calculated |
| 10 | calculated | calculated |
| 20 | calculated | calculated |
| 32 | calculated | calculated |
| 64 | calculated | calculated |

The rows are produced by `compare_components`.

## Mathematical Interpretation

The UI includes a concise interpretation section explaining:

- Image as matrix
- Rank as independent structure
- Eigenvectors as orthogonal directions
- Dominant components
- Projection
- Reconstruction
- Frobenius error as information loss

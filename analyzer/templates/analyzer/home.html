The Eight-Step Mathematical Pipeline

Each stage transforms raw image luminosity into rigorous linear algebraic subspaces.

01 A ∈ [0, 1]m×n

Image to Matrix

Converts image pixels into grayscale intensity values normalized onto the real unit interval [0, 1].

Resized to 64 × 64 floats
02 ρ(A) ≤ min(m,n)

Matrix Rank

Determines the number of linearly independent row and column vectors using SVD singular value thresholds.

Rank vs dimension analysis
03 ATA vi = λi vi

Eigen Analysis

Forms symmetric positive semi-definite matrix ATA and extracts real eigenvalues and orthogonal eigenvectors.

Spectral decomposition
04 Vk = [v1…vk]

Component Selection

Sorts eigenvalues in descending order and retains the top k principal eigen-directions capturing maximal variance.

Dimensionality reduction
05 P = A · Vk

Matrix Projection

Projects original 64-dimensional row space onto the optimal k-dimensional subspace spanned by Vk.

(64 × 64)(64 × k) = 64 × k
06 Ak = P · VkT

Reconstruction

Re-synthesizes low-rank matrix approximation Ak back into the full 64 × 64 pixel domain.

(64 × k)(k × 64) = 64 × 64
07 ‖A − Ak‖F

Error Analysis

Computes Frobenius matrix norm difference and relative error percentage between original and reconstruction.

Relative & absolute metric
08 Energy Compaction

Interpretation

Evaluates energy retention, spectral roll-off, and low-rank compression efficiency for viva and reporting.

Optimal rank-k approximation
